# DSH Hub · 一期设计交付说明

- **阶段**：一期（高保真交互原型）已完成并冻结，等待走查反馈后再进入二期。
- **需求来源**：`dsh-plugins/dsh-hub-desktop/docs/PRD.md`（§6.1 状态语义、§7 视觉方向、§8 文案原则）。
- **交付形态**：单文件 HTML 原型，macOS 窗口形态，明暗主题可实时切换，离线可直接打开。

## 1. 交付文件

| 文件 | 说明 |
|---|---|
| `dsh-hub-desktop.html` | 主交付物。全部界面、状态机与交互脚本内联，双击即可运行 |
| `brand-spec.md` | 视觉规范与 token 真理源：明暗双主题六个基础 token、六态语义色阶、字体栈、5 条视觉语言规则 |
| `一期交付说明.md` | 本文件。范围、走查路径、核验结论、已知限制 |

## 2. 信息架构

**四个视图**（`data-od-id`：`view-home` / `view-detail` / `view-workspace` / `view-settings`）

1. **工作台**：实例总览表格（名称、类型、状态、地址、最近活动）+ 顶部统计，附「新建实例」入口。
2. **实例详情**：运行信息、通道与凭据、审计记录、危险操作四组卡片。
3. **工作区**：内嵌 dsh 网页面，顶部工具条含「实例详情」「重连」，未连接时以浮层给出连接/失败原因，不暴露空的对话面。
4. **设置**：通用、连接、凭据与安全、关于。

**五个浮层**：认证面板（`auth-panel`）、指纹确认（`fingerprint-dialog`）、三步创建向导（`wizard`）、托盘菜单（`tray-menu`）、危险操作二次确认（`confirm-dialog`）。

**侧边栏**：实例列表按类型（本地 / SSH / 远程）分组或平铺，可收起为 64px 缩略轨道（仅类型图标 + 叠加状态点），底栏为图标化搜索 / 新建 / 设置 / 明暗切换。

## 3. 六态状态机

| 状态 | 语义色 | 触发 |
|---|---|---|
| `idle` | 灰 `--idle` | 初始；未连接 |
| `connecting` | 蓝 `--info` | 点击连接 / 重连中 |
| `auth` | 黄 `--warn` | 需登录、会话过期、需二次验证 |
| `interrupted` | 黄 `--warn` | 已连接后通道断开，自动重连中 |
| `connected` | 绿 `--ok` | 通道就绪，可进入工作区 |
| `error` | 红 `--danger` | 连接失败、凭据错误 |
| `locked` | 红 `--danger` | 连续验证失败触发锁定 |

状态不靠颜色单独表达：状态点 + 文案 + 图标三重编码，类型徽标另用线性图标区分，色盲友好。

## 4. 走查路径（内置演示触发点）

| 路径 | 触发方式 |
|---|---|
| 连接成功 | 侧边栏选任一实例 → 「连接」（约 1.15s 后进入工作区并弹出提示） |
| 指纹确认（首次 / 变更） | 「GPU 实验机」连接时弹出确认浮层 |
| 认证面板全流程 | 需登录实例：密码 → 验证码 → 备份码；`初始密码` 实例额外走首次改密 |
| 登录失败与锁定 | 验证码输入 `000000` 触发失败，累计 5 次进入 5 分钟锁定倒计时（其余 6 位数字视为通过） |
| 会话过期 | 「版本尝鲜」（远程）连接后约 9s 工作区被会话过期浮层覆盖 |
| 断线自动重连 | 「服务器 · 主力」（SSH）连接后约 4.2s 显示重连横幅，约 2.6s 后恢复 |
| 创建向导 | 侧边栏「新建」→ 本地 / SSH / 远程三步 |
| 危险操作 | 实例详情 → 移除实例，需在确认框输入实例名 |

## 5. 键盘与持久化

- `⌘B` / `Ctrl+B` 收起或展开侧边栏。
- `localStorage`：`dshhub.theme`（主题）、`dshhub.rail`（侧边栏收起态）、`dshhub.group`（分组方式），刷新后保持。

## 6. 核验结论

- 结构：所有视图、浮层、重复卡片均带 `data-od-id`；无未闭合标签，无占位符（`{{}}` / `[REPLACE]` / `.ph-img`）残留。
- 颜色：`:root` / 深色主题块之外无原始 hex，全部走 token 与 `color-mix()`；明暗两套同名 token 与 `brand-spec.md` 一致。
- 交互：hover / `:focus-visible` / 选中 / 禁用态均定义且前景背景成对变化；聚焦元素有可见焦点环；`--accent` 每屏不超过两次（主按钮 + 选中指示）。
- 脚本：`node --check` 解析通过；无 `scrollIntoView`；无 emoji 图标。
- 响应式：920px 以下回落单列布局，顶栏可换行，无横向滚动。

## 7. 已知限制

1. 原型为纯前端演示，不连接真实 Harness；连接、认证、重连、会话过期均由定时器模拟。
2. 工作区内嵌 dsh 面为占位渲染，未加载真实网页内容。
3. 凭据、指纹、审计记录为示例数据。
4. 未做真实的密钥链读写、代理与端口转发设置项（设置页中相关条目为静态展示）。

## 8. 二期候选

1. 实例列表虚拟滚动与大批量实例（50+）下的性能与信息密度策略。
2. 日志/端口转发面板与工作区多标签。
3. 设置项落地为真实可配置项（代理、端口、密钥链、自动重连策略）。
4. 深色高对比与「减少动态效果」的完整走查。
