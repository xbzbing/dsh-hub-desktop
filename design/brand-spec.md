# DSH Hub · 视觉规范（brand-spec）

来源：`docs/PRD.md` §7 视觉与品牌方向 + §6.1 状态语义 + §8 文案原则。
无外部设计系统注入，规范从上述来源抽取，作为原型唯一的 token 真理源。

**一句话**：macOS 原生工具类应用的克制语言——DeepSeek 深蓝只用于「主操作 + 选中态」，状态色自成一套语义色阶，明暗双主题共享同一套 token 名。

## 1. 六个基础 token（OKLch）

| token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `oklch(0.982 0.003 265)` | `oklch(0.185 0.012 265)` | 侧边栏、页面底 |
| `--surface` | `oklch(1 0 0)` | `oklch(0.232 0.014 265)` | 窗口、卡片、浮层 |
| `--fg` | `oklch(0.24 0.02 265)` | `oklch(0.955 0.006 265)` | 正文 |
| `--muted` | `oklch(0.54 0.015 265)` | `oklch(0.70 0.015 265)` | 次级文案、行摘要 |
| `--border` | `oklch(0.912 0.008 265)` | `oklch(0.325 0.015 265)` | 发丝线、分组边界 |
| `--accent` | `oklch(0.52 0.19 265)` | `oklch(0.66 0.17 265)` | 主按钮填充、选中指示 |

派生：`--accent-ink` 浅色为白、深色为近黑 `oklch(0.17 0.02 265)`——保证「填充上的文字」两种主题都 ≥ 4.5:1，而不是把品牌蓝调浅到读不清。

## 2. 状态色阶（PRD §6.1 六态）

| 语义 | 浅色 | 深色 | 对应状态 |
|---|---|---|---|
| `--idle` | `oklch(0.66 0.01 265)` | `oklch(0.62 0.012 265)` | 未连接 |
| `--info` | `oklch(0.58 0.14 250)` | `oklch(0.70 0.14 250)` | 连接中 |
| `--warn` | `oklch(0.70 0.14 78)` | `oklch(0.80 0.14 82)` | 需登录 / 锁定 / 重连中 |
| `--ok` | `oklch(0.60 0.14 152)` | `oklch(0.74 0.15 152)` | 已连接 |
| `--danger` | `oklch(0.56 0.19 27)` | `oklch(0.68 0.18 27)` | 错误 / 破坏性操作 |

每个语义色派生 `*-soft`（14% 混入 surface，作 chip 底）与 `*-ink`（80% 混入 fg，作 chip 文字），色偏不使用原始 hex。

## 3. 字体栈

```
--font-display: -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Microsoft YaHei', system-ui, sans-serif
--font-body:    同上（工具类/信息密集场景，单字族是刻意的选择）
--font-mono:    ui-monospace, 'SF Mono', Menlo, 'JetBrains Mono', monospace
```

不引入 webfont：桌面应用必须与系统渲染一致，且离线可用。`--font-mono` 只用于数字、地址、指纹、验证码、时间戳（`.num`）。

## 4. 观察到的规则

1. **accent 是交互色，不是装饰色**：全应用只有主按钮填充、侧边栏选中指示条、开关打开态、焦点环四处使用 `--accent`；标题、徽标、卡片、图标一律用 `--fg` / `--muted` / 语义色。
2. **状态不靠颜色单独表达**：状态点 + 文案 + 图标三重编码；实例类型徽标（本地/SSH/远程）用不同线性图标区分，颜色仅作辅助，满足色盲友好。
3. **浮层阴影分层**：登录面板/对话框 `--shadow-layer` > 菜单 `--shadow-pop` > 卡片 `--shadow-1`，窗口本体 `--shadow-win`；层次靠阴影与高度差，不靠描边加粗。
4. **圆角 8/10/12/14**：输入与菜单 8–10，卡片 12，浮层 14；发丝线 1px，选中指示条 2.5px。
5. **动效 150–250ms**，重连类循环动效周期 ≥ 1s 且 `prefers-reduced-motion` 下降级为静态。
