## 概述

本版补齐插件排障最常缺的定位信息：本地安装的插件显示真实源码目录与对应的 GitHub 仓库，GitHub 安装显示安装来源地址；不再展示可能 404 的 npm 页和没有来源的发布时间。编辑实例的「应用启动时自动拉起」改为开关。发布流程同时迁到 GitHub Actions，安装包改在 Windows runner 上原生构建。

## 亮点

- **插件详情显示本地安装目录**：`file:`/`link:` 安装现在解析出绝对源码目录并可复制；普通仓库、linked worktree 与 submodule 的 `.git` 指针都能找到实际配置。
- **来源地址按安装方式给出**：本地安装优先读工作树 git remote 的 GitHub 地址（读不到回落到包清单），GitHub 安装展示安装来源，npm 安装仍用包清单；非 npm 安装不再显示无法确认的 npm 包页，发布时间只对可查 npm 的插件展示。同时修正 pnpm 列表里 `github:` / `codeload` 形态的来源判定。
- **自动拉起改用开关**：编辑实例对话框里「应用启动时自动拉起」由复选框改为开关，开关在前、文案在后，整行可点，键盘空格切换；保存语义不变。
- **发布改由 GitHub Actions 触发**：Actions 页面手动输入版本，workflow 先确认该提交 CI 已成功，再跑门禁、在 `windows-latest` 上构建未签名安装包，推 tag 并停在 Draft；发布脚本仍做版本、说明与资产白名单核验。

### 依赖与测试
