## 概述

本版本在安装插件前增加静态安全检查，补齐远程实例的代理配置，并让插件确认框在高风险与信息过载时都更容易判断。

## 亮点

- **插件安装前的静态安全检查**（ADR-0017、ADR-0018）：解析出精确版本后、下发 `dsh plugin add` 之前，读取 registry 元数据并静态解析 tarball，不执行包内代码。检查收敛为来源与发布者、包体完整性、安装脚本、代码特征、名称与依赖、已知漏洞六类；面板逐项给出等级与证据（`文件:行号 · 规则标签`），只回传位置不回传源码。结构性失败——哈希不符、包名/版本与元数据不一致、包内路径穿越——直接阻止安装；内容特征、安装脚本、名称/声誉与恶意软件通告属于启发式判断，可能误报，核对证据后可以「仍要安装」。主进程用同一份放行口径做最终闸门，不只依赖界面。可在「设置 → 安全」整体关闭。
- **远程实例代理**：远程 HTTP 实例的连接配置可选直连、HTTP 代理或 SOCKS5 代理。HTTP 代理同时用于 http 与 https 目标；SOCKS5 不支持用户名/密码认证，界面直接说明。需要认证的代理密码保存在系统凭据保险库，不写入实例配置，编辑时可留空保持不变，也可显式清除。
- **代理即时修改**：实例详情的连接方式卡新增「编辑代理」，不必进入整套实例编辑；保存后代理立即落到实例分区并就地重新导航工作区，端口、主机与凭据校验与实例编辑共用同一套规则。
- **复制访问 token**：本机实例详情的连接方式卡新增「复制 token」，把当前实例的访问 token 直接复制到剪贴板；非本机实例给出不可用说明。

### 修复与体验

- **仿冒提示更准**：与已装插件同 scope 的包不再被判为仿冒——同一发布者的第二个插件、以及升级自身都会命中；名称或 scope 相似时，提示写明比对的是哪个已装插件。
- **注释不再误判为凭据外发**：代码特征扫描跳过注释，并正确区分字符串、模板字面量与正则字面量。插件注释里提到 `.npmrc`、`fetch(`、`undici` 不再触发「凭据外发」。
- **凭据保险库改用 safeStorage 异步 API**：密码与 token 的加解密不再走已弃用的同步接口，消除 Electron 弃用警告，主进程读写凭据时也不再阻塞。
- **安全检查面板与确认框**：判定为未发现明显风险时面板只留标题行，明细按需展开；插件安装与升级确认框的安装源、将升级到、安全检查三块信息栏可折叠，展开安全检查或查看详情时自动收起安装源。正文滚动到边界时内容渐隐进页脚，不再被硬线切断。

### 依赖与测试

- 运行时依赖仍为零（`dependencies` 为空由测试守护）；本版无新增依赖。
- 单测 1739 项通过（另 1 项按平台跳过）；E2E 78 项全部通过。
- 测试侧：E2E 按 spec 并行（默认 4 个 worker），插件用例从单个 55s 的文件拆成 5 个 spec，全量耗时从 2m54s 降到约 1m；CI 在运行前补齐 Electron 二进制并加缓存，避免首次运行时下载超时。
