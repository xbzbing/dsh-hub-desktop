# DSH Hub v0.1.3

- 发布日期： 2026-09-23
- 标签： `v0.1.3`

## 分发方式

- `source-only`

## 概述

本版本是功能大版本：新增 **dsh 版本管理**（详情页检测与一键升级、新建实例版本下拉、安装进度实时可见）、**侧栏实例快捷键**（按住 ⌘ 显示序号、数字键即时切换）、详情页底部信息栏、设置页空间管理、应用内「关于」面板。

本版本不附带官方二进制：发布只包含源码与 Release Note，使用者需自行准备构建环境并从源码构建。本地构建产物未签名、未公证，仅适用于开发、本机验证或受控测试。

## 从源码构建

需要 Node 22+、pnpm 11，以及目标平台对应的构建环境：

```bash
pnpm install
pnpm build
pnpm test
pnpm dist:mac    # macOS 本地构建
# 或 pnpm dist:win  # Windows 本地构建
```

本地构建生成的产物未签名、未公证，仅适用于开发、本机验证或受控测试，不随发布上传。

## 亮点

- **dsh 版本管理**：详情页显示当前版本与镜像最新版本，一键升级走「停止 → 安装 → 版本写回 → 重启」的单飞编排，进度实时驱动进度条与底部信息栏日志；新建实例的版本下拉默认「跟随最新稳定版」，可显式选定历史版本，选项取镜像最近 10 个（最新在上）。版本元数据从安装队列拆到独立队列并加 60 秒缓存，检查更新与版本列表不再被安装阻塞；npm 镜像可配置，内网可走 `DSH_HUB_NPM_REGISTRY` 或设置页镜像项。
- **侧栏实例快捷键**：按住 ⌘（Windows/Linux 为 Ctrl）满 0.5 秒，侧栏按当前可见顺序显示 #1–#9 序号，松开或失焦即收起；⌘+数字立即切换实例、不等待序号显示。工作区原生视图持有键盘焦点时，主进程按白名单把修饰键与数字组合转发给渲染层，切换在工作区内同样生效。
- **详情页底部信息栏**：常驻单行滚动展示运行状态与安装进度日志，「更多」打开宽屏日志对话框（700px），支持复制与清空；运行环境卡片新增「关闭实例」。
- **设置：空间管理与界面语言**：新增隔离空间管理入口；界面语言可跟随系统（也支持显式固定中文/英文），打包不再裁剪 Chromium 语言包。
- **应用内「关于」面板**：应用菜单（macOS 为 App 菜单，Windows/Linux 为「帮助」菜单）新增「关于 DSH Hub」，以**独立叠加窗口**呈现——与主窗口完全重合的透明子窗口直接浮在当前页面（含内嵌工作区）之上，打开与关闭都不切换页面、不隐藏工作区。面板展示应用版本、项目主页入口，以及实际运行的 Electron、Chromium、Node.js、V8 版本；原生关于面板放不下这些内容（`setAboutPanelOptions` 的 `website` 仅在 Linux 生效），因此改用应用内对话框呈现。

### 修复

- 打包产物在 ready 前把 Chromium 语言钉为系统语言：macOS 裁剪后 app 级 `.lproj` 空目录不被复制，`getLocale()` 回落 `en-US`，没有已存语言偏好的新实例会整站显示英文。
- 对话框统一支持 Escape 关闭：关闭逻辑上移到窗口级关闭栈（焦点无需落在对话框内，多层浮层只关最上层），编辑实例对话框一并生效；打开即聚焦对话框本身，Tab / Shift+Tab 焦点只在对话框内圈闭，不再落到背后的主窗口；容器聚焦不再画蓝色焦点描边。
- 「关于」改为独立叠加窗口：浮在宿主页面（列表、详情、设置页、内嵌工作区）之上，打开与关闭都不跳转、不隐藏工作区视图；右上角、遮罩、Escape 关闭的都是叠加窗口本身。
- 隐藏工作区原生视图时（向导打开场景）把键盘焦点交还宿主渲染层：视图隐藏后 macOS 不会自动撤下它的键盘焦点，浮层的 Escape/Tab 输入会落进不可见的工作区。
- 实例详情「连接方式」「运行环境」两张卡片放开文本选中复制（覆盖 body 的 `user-select: none`，按钮仍不可选）。
- 登出清理分区会话失败时降级为尽力而为，登录态仍被遗忘并写入审计留痕。
- Windows 下 npm 调用方式解析修正；打包前显式准备 Electron 二进制（44 起按需下载）；移除无效的 NSIS 配置；Windows 下应用图标重建，修复渲染为黑块的问题。
- 系统语言探测改用 OS preferred languages 并以 `app.getLocale()` 兜底；E2E 语言钉住中文，断言不随宿主系统语言漂移。
- 实例详情数据目录由主进程预计算，消除混合分隔符；悬停提示按文本宽度收缩；空间管理折叠标记方向修正；日志对话框加宽。
- 对话框在小窗口内限高、正文滚动、页脚常驻，高内容向导步骤的页脚按钮不再被挤出视口。

### 测试与 CI

- 单元测试 849 项、E2E 31 项，CI 覆盖 ubuntu（xvfb + gnome-keyring）与 Windows 双平台，全绿。
- 发布演练校验：发布只允许 `source-only`，发布说明声明安装包、`SHA256SUMS.txt` 或 `latest-*.yml` 等任何资产一律失败。
- E2E 截图默认写入被忽略的 `hub-data/`，`DOCS_SHOTS=1` 才更新文档截图；补充工作区边界回归与版本管理契约用例。

## 当前限制

- 不提供任何平台的官方二进制；需从源码构建。
- 首次创建本地实例可能需要联网准备 dsh 运行时；内网环境可设置 `DSH_HUB_NPM_REGISTRY`。
- 版本检查仅覆盖 hub 托管的本地实例；SSH / 远程实例暂无获取其 dsh 版本的途径。镜像 `latest` 标签滞后于新发布时，以版本列表最大值为准。

恢复任何平台的二进制分发需要代码签名、公证、干净机器安装验证以及可复核的构建与校验流程，完整门槛见 [发布策略](https://github.com/xbzbing/dsh-hub-desktop/blob/main/docs/release-policy.md)。
