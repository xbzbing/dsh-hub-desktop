# DSH Hub v0.1.3

- 发布日期： 2026-09-23
- 标签： `v0.1.3`

## 分发方式

- `windows-unsigned`

## 产物

- `DSH-Hub-Setup-0.1.3.exe`
- `SHA256SUMS.txt`

## 概述

本版本是功能大版本：新增 **dsh 版本管理**（详情页检测与一键升级、新建实例版本下拉、安装进度实时可见）、**侧栏实例快捷键**（按住 ⌘ 显示序号、数字键即时切换）、详情页底部信息栏、设置页空间管理、应用内「关于」面板，并首次提供 **64 位 Windows 安装包**。安装包未做代码签名：首次运行会出现 SmartScreen「未知发布者」提示，选择「更多信息 → 仍要运行」即可。

macOS 仍不提供官方二进制 —— 未签名、未公证的 `.app` 在 Gatekeeper 下无法正常打开，本地构建产物仅供开发与受控测试。

## 从源码构建

需要 Node 22+、pnpm 11，以及目标平台对应的构建环境：

```bash
pnpm install
pnpm build
pnpm test
pnpm dist:mac    # macOS 本地构建
# 或 pnpm dist:win  # Windows 本地构建
```

本地构建生成的产物未签名、未公证，仅适用于开发、本机验证或受控测试。Windows 安装包由 GitHub Actions 在 `windows-latest` 上按标签构建，随发布上传并附 SHA-256 校验和。

## 亮点

- **dsh 版本管理**：详情页显示当前版本与镜像最新版本，一键升级走「停止 → 安装 → 版本写回 → 重启」的单飞编排，进度实时驱动进度条与底部信息栏日志；新建实例的版本下拉默认「跟随最新稳定版」，可显式选定历史版本，选项取镜像最近 10 个（最新在上）。版本元数据从安装队列拆到独立队列并加 60 秒缓存，检查更新与版本列表不再被安装阻塞；npm 镜像可配置，内网可走 `DSH_HUB_NPM_REGISTRY` 或设置页镜像项。
- **侧栏实例快捷键**：按住 ⌘（Windows/Linux 为 Ctrl）满 0.5 秒，侧栏按当前可见顺序显示 #1–#9 序号，松开或失焦即收起；⌘+数字立即切换实例、不等待序号显示。工作区原生视图持有键盘焦点时，主进程按白名单把修饰键与数字组合转发给渲染层，切换在工作区内同样生效。
- **详情页底部信息栏**：常驻单行滚动展示运行状态与安装进度日志，「更多」打开宽屏日志对话框（700px），支持复制与清空；运行环境卡片新增「关闭实例」。
- **设置：空间管理与界面语言**：新增隔离空间管理入口；界面语言可跟随系统（也支持显式固定中文/英文），打包不再裁剪 Chromium 语言包。
- **应用内「关于」面板**：应用菜单（macOS 为 App 菜单，Windows/Linux 为「帮助」菜单）新增「关于 DSH Hub」，展示应用版本、项目主页入口，以及实际运行的 Electron、Chromium、Node.js、V8 版本。原生关于面板放不下这些内容（`setAboutPanelOptions` 的 `website` 仅在 Linux 生效），因此改用应用内对话框呈现。
- **64 位 Windows 安装包**：NSIS 安装程序，默认预选所有用户安装；由标签流水线在 Windows 上构建，避免在 macOS 上交叉构建产生与正式环境不一致的产物；应用图标重建修复了 Windows 下渲染为黑块的问题。

### 修复

- 登出清理分区会话失败时降级为尽力而为，登录态仍被遗忘并写入审计留痕。
- Windows 下 npm 调用方式解析修正；打包前显式准备 Electron 二进制（44 起按需下载）；安装包资产名统一连字符形态，与发布说明、校验和清单一致；移除无效的 NSIS 配置。
- 系统语言探测改用 OS preferred languages 并以 `app.getLocale()` 兜底；E2E 语言钉住中文，断言不随宿主系统语言漂移。
- 实例详情数据目录由主进程预计算，消除混合分隔符；关于对话框不再自动聚焦容器；悬停提示按文本宽度收缩；空间管理折叠标记方向修正；日志对话框加宽。

### 测试与 CI

- 单元测试 837 项、E2E 28 项，CI 覆盖 ubuntu（xvfb + gnome-keyring）与 Windows 双平台，全绿。
- 发布演练模式校验：`windows-unsigned` 只接受本版安装包与 `SHA256SUMS.txt`，夹带 macOS 二进制、`latest-*.yml` 或未白名单资产一律失败。
- E2E 截图默认写入被忽略的 `hub-data/`，`DOCS_SHOTS=1` 才更新文档截图；补充工作区边界回归与版本管理契约用例。

## 当前限制

- Windows 安装包**未签名**：SmartScreen 会提示「未知发布者」，企业 EDR/MDM 策略可能拦截；自动更新不对外可用。
- 未提供 macOS 官方二进制；macOS 用户需从源码构建。
- 首次创建本地实例可能需要联网准备 dsh 运行时；内网环境可设置 `DSH_HUB_NPM_REGISTRY`。
- 版本检查仅覆盖 hub 托管的本地实例；SSH / 远程实例暂无获取其 dsh 版本的途径。镜像 `latest` 标签滞后于新发布时，以版本列表最大值为准。

恢复 macOS 二进制分发需要 Apple Developer Program、Developer ID 签名、公证与 staple、干净机器安装验证，以及可复核的更新元数据和校验和。完整门槛见 [发布策略](https://github.com/xbzbing/dsh-hub-desktop/blob/v0.1.3/docs/release-policy.md)。
