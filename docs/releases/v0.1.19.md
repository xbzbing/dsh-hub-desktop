## 概述

本版修复 Windows 上 Alt+Tab 切换应用后侧栏 #1–#9 序号角标一直停留的问题：工作区原生视图持焦时，窗口失焦信号到不了 Hub 渲染层；改由主进程在窗口级失焦、隐藏与重新聚焦时补发重置，角标随窗口状态可靠收起。

## 亮点

- **Alt+Tab 后序号角标不再残留**：侧栏的 #1–#9 角标依赖切换修饰键的 keyup 与窗口 blur 收起；工作区 WebContentsView 持焦时 Hub 渲染层收不到 window blur，Alt 的 keyup 也会随系统切换被吞掉。现在主进程监听 Hub 窗口的 blur / focus / hide，通过既有工作区快捷键通道补发 `reset`，渲染层清空按住态并取消显示计时；切回窗口后角标立即消失，下一次按住 Alt 重新显示。
- **切换手势不变**：仍是 Windows/Linux 的 Alt+数字、macOS 的 ⌘+数字；只调整角标生命周期，不改键位与切换路径。同一机制也覆盖 macOS 上 ⌘+Tab 的同类场景。
