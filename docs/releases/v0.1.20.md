## 概述

本版给本机实例加上存活策略：进程意外退出后按退避自动拉起，开关在实例详情「连接方式」下方的「实例管理」小节切换即保存。插件列表把已禁用插件排到末尾；工具链同步升到 Electron 45.5、Vite 8、React 19 与 pnpm 12.23。

## 亮点

- **本机实例意外退出自动重启**：Hub 拉起的本机实例退出后（含 `code=0`）在后台重新拉起，无需人工再点启动。退避与 SSH 隧道同口径：首次 1s，之后 2s、4s…上限 30s；崩溃前已稳定运行满 60s 则重置退避与失败计数。只有「从未就绪」的连续失败计数达到 5 次才放弃并提示手动排查，运行过再崩溃的实例持续按上限重试。手动停止、删除实例、接管进程与应用退出都会取消待执行的重启，不会在用户停手后偷偷复活；启动超时与健康探测失败仍走原失败终态，不用自动重试掩盖配置问题。
- **「实例管理」开关在实例详情即时保存**：两个开关（应用启动时自动拉起、进程意外退出时自动重启）从编辑实例弹窗移到详情页「连接方式」卡片下方，切换后立即写注册表，失败弹提示并保留原值；只对本机实例显示，SSH 与 HTTP 实例没有本地进程可管理，不出现该小节。运行中关掉开关，下一次退出就不再重启。
- **已禁用插件排到列表末尾**：插件列表先列启用中的插件、再列已禁用插件，其余排序不变；启用或禁用后位置即时更新，排查时不必在长列表里找灰掉的条目。
- **工具链升级**：Electron 45.5.0（Chromium 156.0.8078.109 / Node 24.22.3 / undici 7.30.2）、Vite 8.3.8、React 19.3.1、TypeScript 5.9、pnpm 12.23.0（随包 pnpm 10.34.9），CI 的 Actions 升到当前主版本。Vite 8 与 React 19 的取舍见 ADR-0022：TypeScript 留在 5.9 版本线是 typescript-eslint 8 的 peer 上限，`@vitejs/plugin-react` 保持 5.2.0 以避免引入额外构建链。
