# DSH Hub v0.1.2

- 发布日期： 2026-09-20
- 标签： `v0.1.2`

## 分发方式

- `source-only`

## 概述

本版本将运行时从 Electron 43 升级到 Electron 44（Chromium 150 → 152），并补充 E2E 隐藏窗口运行模式与工作区进入断言稳定性修复。升级后的 Chromium 152 仍在官方支持窗口内，安全基线前移一个主版本。

GitHub Release 当前仅发布标签、发布说明以及 GitHub 自动生成的源码归档（`Source code (zip)`、`Source code (tar.gz)`）。不提供官方 `.app`、`.dmg`、`.zip`、`.exe`、自动更新元数据或校验和文件。

## 从源码构建

需要 Node 22+、pnpm 11，以及目标平台对应的构建环境：

```bash
pnpm install
pnpm build
pnpm test
pnpm dist:mac    # macOS 本地构建
# 或 pnpm dist:win  # Windows 本地构建
```

本地构建生成的产物未签名、未公证，仅适用于开发、本机验证或受控测试；构建成功不代表可以安全公开分发。请勿将它们作为官方 Release 资产重新上传。

## 亮点

- **Electron 44 运行时升级**：Chromium 150.0.7871.250 → 152.0.7977.130，Node 24.21.0。Electron 44 的破坏性变更（clipboard 模块重构并移出 renderer、`select-client-certificate` 回调参数可空、ANGLE 静态链接、macOS 12 弃用）经逐一核对，对当前代码零影响：项目不使用 Electron clipboard API，renderer 内为标准 `navigator.clipboard`；不监听客户端证书事件；不依赖 `net.request` 帧请求。typecheck、lint、766 项单测、25 项 E2E 与打包链路全部在 Electron 44 上通过。
- **E2E 隐藏窗口模式**：新增 `DSH_HUB_E2E_HIDDEN` 环境变量，本机开发时可让 Playwright 跑的 Electron 窗口不显示、不进 Dock、不抢焦点，边工作边跑 E2E 不再打断手头操作。
- **工作区进入断言稳定**：工作区 loading 为瞬态状态，明文警告用例改为只断言最终进入工作区，消除偶发时序失败。

### 修复

- 无新增功能缺陷修复；本版本为运行时升级与测试基建改进。

### 测试与 CI

- E2E 25/25 通过（Electron 44.4.3 真机运行），覆盖窗口外壳、preload 桥接白名单、注册表 IPC、外部 dsh 接管、SSH 认证对话框与 UI 基线。
- 发布元数据离线校验（版本与发布说明一致性、electron-builder 无 publish provider、打包脚本结构上不可能误发布）全部通过。

## 当前限制

- 未提供签名和公证的官方桌面安装包，自动更新不对外可用。
- 首次创建本地实例可能需要联网准备 dsh 运行时；内网环境可设置 `DSH_HUB_NPM_REGISTRY`。

恢复官方二进制分发需要 Apple Developer Program、Developer ID 签名、公证与 staple、干净机器安装验证，以及可复核的更新元数据和校验和。完整门槛见 [发布策略](https://github.com/xbzbing/dsh-hub-desktop/blob/v0.1.2/docs/release-policy.md)。
