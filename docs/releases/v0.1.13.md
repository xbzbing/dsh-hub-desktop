## 概述

本版以内部整理为主：收敛日志轮转、IPC 公共类型、运行时读取与界面表单等重复实现，并修正两处边界行为——未连接的实例不再显示「断开工作区」，插件安全扫描不再把正则字面量里的路径与网络特征误判为敏感内容。

## 亮点

- **断开工作区入口跟随连接状态**：详情页只在实例已连接时显示「断开工作区」；已关闭的实例与尚未连通的远程实例不再出现该按钮，避免点了没有效果。
- **插件安全扫描减少误报**：内容扫描先遮住正则字面量再匹配路径与网络特征，JSX 闭合标签也不会吞掉后续代码，源码里的正则表达式不再触发与自身无关的敏感判定。
- **文案表按语言拆分**：中文与英文文案各自成表，聚合器只负责按当前语言取表；硬编码扫描的豁免范围收敛到 catalog 目录，新增语言只需增加一张表并注册一行。
- **共享实现收敛**：按日轮转日志、审计事件构造、GitHub 请求头、已安装版本读取、进程内缓存解析、就绪失败终局、安全取数错误映射与 known_hosts 行解析各自只剩一条实现；渲染层的代理表单字段、插件安全检查派生状态与设置页外链处理也改为复用同一份代码。
- **实例地址统一**：主进程与渲染层共用 `instanceAddress`，本地、SSH 与 HTTP 实例的地址展示不再各算各的。

### 依赖与测试

- 运行时依赖仍为零（`dependencies` 为空由测试守护）；本版无新增依赖。
- 单测 1748 项通过（另 1 项按平台跳过）；E2E 80 项全部通过。新增「断开工作区入口」按连接状态显示的单测，E2E 覆盖未连通远程实例不出现该按钮。
