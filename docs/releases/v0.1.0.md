# DSH Hub v0.1.0

- 发布日期: 2026-09-16
- 标签: `v0.1.0`
- 基线: `docs/开发任务清单.md` T1–T13 全部完成（M1–M4 里程碑出口达成）

DSH Hub 是一个**个人自用**的桌面工具，用来统一管理多个 dsh（DeepSeek Harness）实例：
本地 spawn、SSH 隧道、远程 HTTP 直连三种形态，认证走 `dsh-auth-gateway` 协议
（密码 + TOTP，成功后把 HttpOnly Cookie 注入 webview 分区）。

## 首要说明

本版本产物**未做代码签名与公证**（无 Apple Developer 证书）。首次打开需在
「系统设置 → 隐私与安全性」里允许，或右键选择「打开」。产物**只宜自用**，不建议分发
（原因见下「已知限制」）。

## 亮点

- **三种实例形态**：本地 spawn（端口分配 + `dsh web --expose-internals`）、SSH 隧道
  （TOFU 主机指纹，`StrictHostKeyChecking=yes`，密钥只引用路径不读取）、远程 HTTP 直连
  （端点归一化，拒绝内嵌凭据 / 查询串 / 锚点）。
- **完整两步认证**：密码 + TOTP（支持单请求带码，也支持验证码阶段复用同一次密码重发）、
  锁定倒计时、首次登录的 onboarding 引导；会话失效自动重登并恢复原页面。
- **凭据纪律**：注册表与审计日志**绝不落**密码 / OTP / Cookie / 私钥；审计记录由
  **显式白名单投影**构造（无对象展开），保险库为**逐实例显式勾选**（默认不记住）。
- **中英双语界面**：语言与主题（含跟随系统）即时生效；托盘菜单、开机自启、状态变化通知
  均可配置，且每个开关都驱动真实行为。
- **零运行时依赖**：`dependencies` 为空，`zod` 为 devDependency 并已打包进主进程产物。

## 安装与升级

1. 从 Release 附件下载 `DSH Hub-0.1.0-arm64-mac.zip` 并解压。
2. 校验完整性（可选但推荐）：
   `shasum -a 256 "DSH Hub-0.1.0-arm64-mac.zip"`，与 `SHA256SUMS.txt` 对应行比对。
3. 把 `DSH Hub.app` 拖入「应用程序」。
4. 首次启动若被 Gatekeeper 拦截：右键 → 「打开」，或在「隐私与安全性」中允许。

**升级**：直接用新版本覆盖「应用程序」里的 `DSH Hub.app` 即可。实例注册表
（`<userData>/registry/instances.json`）与偏好（`<userData>/settings.json`）与程序分离，
覆盖安装不会丢失；跨 schema 版本的升级路径由 `tests/upgrade/upgrade-path.test.ts` 用
**真实历史落盘夹具**钉住（含「旧版本读到新版本文件时原字节留档」的回退保护）。

数据目录可用环境变量 `DSH_HUB_DATA_DIR` 覆盖（便于隔离测试）。

## 已知限制

- **未签名未公证**：需手动允许；且 `build/entitlements.mac.plist` 放开了 library validation
  （应用要 spawn **用户自备**的 dsh / ssh 二进制），因此只宜自用。
- **分区 Cookie 为明文**：Electron 43.7 下 Chromium 会把 `dsh_auth` 会话 Cookie 明文写入
  `<userData>/Partitions/inst-<id>/Cookies`，与「记住登录态」勾选无关。这是本版本**显式接受
  的风险**（决策与边界见 `docs/安全走查报告.md` §8 与设计文档 §7.2.1）；UI 文案只承诺
  「不存入保险库」，不做更强的承诺。
- **自动更新未端到端验证**：更新元数据与产物已做字节级校验，但「安装旧版 → 收到更新 →
  完成升级」的闭环需要真实远端与已安装的旧版本，本机无法演练。
- **dsh 运行时需联网安装**：首次创建本地实例会下载 dsh 运行时；内网环境可设
  `DSH_HUB_NPM_REGISTRY=https://registry.npmmirror.com` 加速。
- **Windows 产物未经实机验证**：无 Windows/wine 环境。
