# DSH Hub v0.1.0

- 发布日期: 2026-09-16
- 标签: `v0.1.0`

## 分发方式

- `source-only`

## 概述

DSH Hub 是用于统一管理多个 dsh（DeepSeek Harness）实例的 Electron 桌面工具，支持本地进程、SSH 隧道与远程 HTTP 直连；认证对接 `dsh-auth-gateway`（密码、TOTP 与 HttpOnly Cookie 分区注入）。

GitHub Release 当前仅发布标签、发布说明以及 GitHub 自动生成的源码归档（`Source code (zip)`、`Source code (tar.gz)`）。不提供官方 `.app`、`.dmg`、`.zip`、`.exe`、自动更新元数据或校验和文件。

## 从源码构建

需要 Node 22+、pnpm 11，以及目标平台对应的构建环境：

```bash
pnpm install
pnpm build
pnpm test
pnpm dist:mac    # macOS 本地构建
# 或 pnpm dist:win  # Windows 本地构建
```

本地构建生成的产物未签名、未公证，仅适用于开发、本机验证或受控测试；构建成功不代表可以安全公开分发。请勿将它们作为官方 Release 资产重新上传。

## 亮点

- **多实例管理**：本地 dsh、SSH 隧道与远程 HTTP 端点统一创建、编辑、打开和删除。
- **侧边栏拖拽排序**：支持拖拽调整实例顺序，首页表格同步显示手动排序。
- **认证一体化**：网关登录、TOTP、会话恢复、已存密码静默登录及分区 Cookie 注入。
- **工作区链接**：工作区内 `target="_blank"` 链接自动在系统浏览器中打开。
- **安全边界**：凭据不写入注册表或审计日志；SSH 使用 TOFU 主机指纹确认；WebContentsView 权限与导航受限。
- **工作区生命周期**：可断开内嵌工作区而不停止运行时或清除凭据，随后可从实例列表重新打开。
- **双语与外观**：中文/英文界面、系统主题跟随、托盘、通知和开机自启配置。

## 当前限制

- 未提供签名和公证的官方桌面安装包，自动更新不对外可用。
- 首次创建本地实例可能需要联网准备 dsh 运行时；内网环境可设置 `DSH_HUB_NPM_REGISTRY`。
- Windows 本地构建需 Windows 或兼容的构建环境。

恢复官方二进制分发需要 Apple Developer Program、Developer ID 签名、公证与 staple、干净机器安装验证，以及可复核的更新元数据和校验和。完整门槛见 [发布策略](https://github.com/xbzbing/dsh-hub-desktop/blob/v0.1.0/docs/release-policy.md)。

## 完整变更

这是首个公开 source-only 版本，包含实例注册表与 IPC、本地/SSH/HTTP 三种连接方式、认证与凭据保险库、工作区 Cookie 注入与生命周期控制、审计、双语界面、安全加固和本地打包能力。

### 新功能

- 侧边栏拖拽排序，首页表格同步手动顺序
- 实例排序持久化（IPC reorder 通道）
- 认证面板支持用已保存的密码直接登录
- 工作区 `target="_blank"` 链接在系统浏览器中打开

### 修复

- 会话失效时不再误判为已恢复
- OTP 屏密码输入框因状态耦合自卸载
- 认证面板关闭后丢弃已输入的凭据
- 窗口失焦隐藏提示窗，复焦恢复工作区焦点
- 已打开的工作区不再等待认证探测
- 修复侧栏提示圆角边框缺失
- 同步远程工作区语言
- 拖拽排序放下位置改用 ref 实时记录
- 刷新时清除工作区旧边界
