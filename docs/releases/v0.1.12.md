# DSH Hub v0.1.12

- 发布日期: 2026-11-09
- 标签： `v0.1.12`

## 分发方式

- `windows-unsigned`

## 产物

- `DSH-Hub-Setup-0.1.12.exe`（Windows x64 NSIS 安装包，未签名）
- `SHA256SUMS.txt`（上述安装包的 SHA-256 校验清单）

> 安装包未经代码签名，Windows 首次运行会出现 SmartScreen「未知发布者」提示——点「更多信息 → 仍要运行」即可继续。下载后请用 `SHA256SUMS.txt` 校验完整性。macOS 暂不提供官方二进制，仍需从源码构建。

## 概述

本版本把「检查更新」的结果收回按钮所在行，并在发现新版本时直接弹出带更新内容的对话框；插件升级确认框在解析出目标版本后自动收起安装源。

## 亮点

- **检查更新结果紧跟按钮**：结果不再独占一行把卡片拉高，而是显示在「关于」「检查更新」右侧；「已是最新」与「发现新版本」都只占这一行。
- **新版本更新说明对话框**：发现新版本时自动弹出，标题为最新版本号，正文显示当前版本、发布日期与 Release 的 Markdown 更新内容，底部可「查看发布页」。关闭后行内结果仍在，点击这段文字即可重新打开。
- **升级确认框自动收起安装源**：解析出目标版本后，安装源小节收起，标题行保留当前档位（如「npmmirror（国内加速）」），纵向空间留给版本差异与安全检查；需要改选来源时展开，选择后按新源重新解析并再次收起。

### 依赖与测试

- 运行时依赖仍为零（`dependencies` 为空由测试守护）；本版无新增依赖。
- 更新检查现在随结果下发 Release 正文（Markdown，按字符截断到 2 万），对话框复用现有的净化渲染链路。
- 单测 1741 项通过（另 1 项按平台跳过）；E2E 80 项全部通过，新增「更新结果与按钮同一行、对话框显示正文、关闭后可重开、已是最新不弹框」用例，升级用例覆盖安装源的自动收起与改选。
